# GlassCode — Learn UI. Build Better.

**GlassCode** shares practical UI components with complete HTML and CSS source code.

## What you'll find here
- Ready-to-use HTML and CSS components
- Responsive examples
- Small, practical UI lessons
- Source code you can copy, customize, and build on

## First component
**Glassmorphism Card** — a responsive glass-effect card with a dark background, subtle border, blur, and warm accent.

### Preview locally
1. Open `components/glassmorphism-card/index.html` in your browser.
2. Edit `style.css` to customize the appearance.
3. Copy the HTML and CSS into your own project.
